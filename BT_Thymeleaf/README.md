# BT Thymeleaf - Quản lý khóa học

Project minh họa Spring Boot MVC và Thymeleaf với các chức năng:

- Hiển thị và tìm kiếm khóa học
- Thêm, sửa, xóa khóa học
- Validate dữ liệu form và hiển thị lỗi bằng Thymeleaf
- Dữ liệu mẫu lưu trong bộ nhớ, không cần cơ sở dữ liệu
- Giao diện responsive cho máy tính và điện thoại

## Yêu cầu

- Java 21 trở lên
- Maven 3.9 trở lên

## Chạy project

```powershell
cd BT_Thymeleaf
mvn spring-boot:run
```

Mở trình duyệt tại <http://localhost:8080>.

## Chạy kiểm thử

```powershell
mvn test
```

> Dữ liệu sẽ trở về trạng thái ban đầu sau mỗi lần khởi động lại ứng dụng.
